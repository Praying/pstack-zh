# Build the Lever（打造杠杆）

工作不琐碎时，造出把活干掉的工具（codemod、脚本、生成器，或可重跑的检查），不要手工做。门槛是琐碎与否，不是重复与否。只有一两处显而易见的编辑时才跳过工具。

- 先手工做第一个单元，再造出工具，在这个单元上重跑一遍证明它管用。让它可以安全重跑。
- 确定性工具胜过扇出（fan-out）。真要扇出时，把食谱、验证契约和围栏写成一份技能（skill），让子代理（subagent）读取但无法修改。
- 应用这条原则会产出一个文件。diff 里没有脚本、codemod、生成器或子代理技能，就说明你没应用它。工作比会话更长寿时，把它提交。
- 造能干完活或证明活干成的最小脚本，绝不造框架。
