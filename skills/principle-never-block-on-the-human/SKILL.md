# Never Block on the Human（绝不阻塞在人类身上）

人类是异步监督的。代理（agent）绝不能被堵住。做出合理决策，继续推进，让人类事后纠偏。代码改动可逆又可审查，一个错误决策通常比堵着等更便宜。

- 先推进，再展示。把活干了，把结果亮出来。不要问"该不该做 X？"。直接做 X，然后解释为什么。
- 让系统自愈。发现问题就记录下来，下一轮修掉。
- 不可逆动作仍然需要确认：强制推送、删除生产数据、发出外部消息。
- 可逆动作（写代码、改笔记、拆任务）应当直接推进，不要堵着。
- 产品方向由人类定。执行不该被堵住。
