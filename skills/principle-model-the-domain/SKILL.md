# Model the Domain（为领域建模）

把领域编码进数据结构，而不是散落在条件分支里。合适的结构让非法状态无法表示，顺手删掉分支。

优先用状态机，不用散落的布尔值或阶段检查。用带类型的模型，不用松散参数。用 map、注册表或可辨识联合（discriminated union），不用散布在文件间的分支。用 reducer，不用临时起意的修改。访问模式需要时，用索引、队列或规范化集合。

不要硬套。形状清晰、局部、不太会长大时，就留着无聊的代码。对那种只添间接层、既不删分支也不消灭非法状态的抽象，保持怀疑。

跳过它的信号：某个功能让 if/else 链又长出一个分支，或者冒出第二个必须与第一个保持同步的布尔值。
