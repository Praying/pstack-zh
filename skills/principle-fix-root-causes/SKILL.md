# Fix Root Causes（修复根因）

修缺陷，不修冒头的地方。根因是系统第一次做了不该做的事、或者没处理该处理的状态的地方。

- 先复现。连问"为什么"，直到答案落到代码里的一个错误决策。卡住时，加插桩观测，读出真实状态。
- 问一句触发症状的状态是否合法。合法，就在代码出问题的地方处理它。它本不该存在，在那儿加检查只会把 bug 藏起来，所以要找到是谁产生了它。防护、重试、被吞掉的错误、被钳制的值、被丢弃的状态，是藏 bug 的惯用手法。
- 修模式，不修个例。找出所有带着同一缺陷的地方。
- 如果决定性事实是深挖才拿到的，就提出那个便宜且常开的信号，让它一眼可见。
