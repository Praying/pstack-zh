### Visual parity（视觉等价）

**你拥有像素级等价。基线（baseline）就是规格。你不许动它。** 等价靠图像 diff 验证，不靠肉眼。

1. 先立基线，在任何迁移之前立。基线是一套视觉回归工装（harness），把当前组件的各个状态逐一截图，比对两个实现时把目标也一并截下。没有基线，就没有等价声明。这是阻塞性前置条件，不是事后跟进项。
2. 反捷径条款，写明并守住：不许改工装，不许篡改基线，不许为了让 diff 通过而重构组件。基线看着不对，就停下来问，不许改它。
3. 一次迁移一个组件。跨工作树（worktree）并行，每个组件一个负责人（**separate-before-serializing-shared-state** 原则（principle）技能（skill））。共享原语作为阻塞性阶段先行迁移。
4. 在相配的界面上经由控制技能，用图像 diff 把每个组件对着它的基线验证。diff 非零即失败。追查像素差值。每个组件跑 `/loop`，直到 diff 为零。
5. 每个组件或每个安全批次跑 **Opening a PR** 手册（playbook）。

**回复：** 迁移了哪些组件、各自的 diff 结果、基线工装的位置、还剩什么。
