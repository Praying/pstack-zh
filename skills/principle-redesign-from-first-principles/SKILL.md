# Redesign From First Principles（从第一性原理重新设计）

整合一个变更时，不要把它钉在现有设计上。像这个需求从一开始就是基础假设那样重新设计。

- 读完所有受影响的文件，理解当前设计
- 问一句："如果带着这个新需求从零开始写，我们会建成什么？"
- 把变更传播到每一处引用：类型、文档、示例、理由章节
- 把整个重新设计想透，再增量交付

这就是往现有设计里整合变更时保住选择权的方法。
