# Explain the Number（解释这个数字）

- **先写下决策，再跑。** 指明哪种结果会改变这个决策，以及噪声底线（noise floor）。当运行间的波动大于效应本身时，就停。
- **问一句"为什么不翻倍？"** 从运行中采集的剖析数据或计数器出发，指出限定结果的资源或代码路径。靠读代码猜出来的不算限制因素。
- **列出这个数字还可能在测什么**（错误、被跳过或被缓存的工作、从未运行的代码、没调优的一侧、噪声、小到无关紧要的部分），并用证据逐项排除。
- **把运行次数、波动和限制因素与数字一起保存。**

对性能数字，跑 [benchmark-checklist](../benchmark-checklist/SKILL.md) 技能（skill）。对评测结果，问三个问题：每次运行是否都完成了任务，差距在不同试次和不同模型之间是否成立，场景是否重要。
